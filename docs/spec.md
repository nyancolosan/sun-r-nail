## プロンプト

あなたはプロのWebデザイナー兼フロントエンドエンジニアです。
小規模ネイルサロンの公式ホームページ（1ページ構成）を新規に作ってください。

### 1. サロン情報（仮。後で差し替える前提）
- サロン名：sun_r（ブランド名の文字は小文字の「sun_r」を、他の英字と同じ Jost（400・字間0.12〜0.14em）で。アンダースコアも含めてそのまま表記。ロゴマークは別途画像で支給）
- 業態：完全予約制・マンツーマンのプライベートサロン
- 住所：載せない（住所欄・地図・Googleマップのリンクは作らない）
- アクセス：南海電鉄 岸和田駅 中央出口から徒歩2分
- 営業時間：10:00〜20:00／定休日：【未定】
- 予約先：ネット予約＝ホットペッパービューティー https://beauty.hotpepper.jp/kr/slnH000732849/
- Instagram：https://www.instagram.com/sun___r_nail/（アカウント名 sun___r_nail）
- LINEは使わない（LINEのボタン・リンク・文言は一切入れない）
- ターゲット：20〜40代の働く女性。オフィスでも浮かない上品なネイルを求める人

### 2. 技術要件
- 素のHTML / CSS / JavaScript のみ（フレームワーク・ビルド不要）。Cloudflare（Workers の静的アセット配信）でそのまま公開できる構成
- ファイル構成：
  - `index.html`
  - `css/style.css`
  - `js/main.js`
  - `data/site.json` … 店名・アクセス・営業時間・メニュー・料金・スタイリスト・予約URLをすべてここに集約。HTML側はJSで読み込んで描画する（オーナーがこのファイルだけ編集すれば更新できるように）
- 外部読み込みは Google Fonts のみ
- モバイルファースト。375px〜1440pxで崩れないこと

### 3. デザイン方針（生成り×黒、アクセントにブルー・ミニマル）
- **色は「生成り（背景）」「黒（文字）」「ブルー（アクセント）」の3つだけ。それ以外の色は使わない**
  - 背景（生成り）：`#F8F7F3`（ロゴ画像の背景色と同じ）
  - 文字（黒）：本文・見出し `#111111`／サブテキスト `#555555`／注記 `#6B6B6B`
  - 区切り線：`#E6E1DB`
  - アクセント（ブルー）：`#134CA5`。**使う場所は以下に限定**し、本文や見出しには使わない
    - 主ボタン（ブルー塗り・生成り文字）
    - セクション上の英字ラベル（MENU & PRICE など）とメニューのカテゴリ名
    - リンクのホバー色、フォーカスリング
    - ご予約セクションの背景（文字・ボタンは生成り）
  - 副ボタンは黒1px枠線・黒文字
- フォント：和文は全て Zen Kaku Gothic New（見出し500・本文400）／英字はブランド名「sun_r」も含めてすべて Jost 400
- セクション見出しの上に英字ラベル（例：MENU & PRICE、ACCESS）を小さく、字間広め（0.18em）
- ボタンはロゴの丸みに合わせて角丸ピル型（`border-radius: 999px`）。主ボタン＝ブルー塗り生成り文字、副ボタン＝黒1px枠線
- それ以外（カード・表など）は角丸なし、セクションは1pxの線で区切る
- 余白をたっぷり。セクション上下 `clamp(56px, 8vw, 112px)`、行間 1.9
- **写真・画像・イラストは一切使わない**（ロゴのみ例外）。文字・余白・線だけで構成するミニマルなサイトにする
- 装飾（グラデーション・アイコン）は入れない。影とアニメーションは「UX要件」に書いた控えめなものだけ
- 禁止：生成り・黒（グレー）・ブルー以外の色、ブルーの使いすぎ、絵文字、派手なホバー効果

### 4. ページ構成（上から順に）
1. **ヘッダー**：ロゴ画像（36px）＋「sun_r」（Jost 400・20px）／ナビ（MENU・STYLIST・FAQ・ACCESS）／「SOUND OFF／ON」ボタン（ピル型・枠線）＋「ご予約」ボタン。スクロールで背景に薄い影。スマホではハンバーガーメニュー（全画面オーバーレイ、ESCとリンク選択で閉じる）
2. **ヒーロー**：キャッチコピーや説明文は置かない。中央揃えで「ロゴ画像 `images/logo.svg`（幅160〜220px。`<h1>` の中に `alt="sun_r"` で配置）」→ その下に「sun_r」（Jost 400、28〜36px、黒）→ すぐ下に小さな英字ラベル「PRIVATE NAIL SALON」（ブルー）→ ボタン2つ（空き状況を見る／メニューと料金）。上下の余白を大きく取る
3. **メニュー・料金**：「ご新規様」「リピーター様」の2つのピル型タブで料金を切り替える（初期表示はご新規様。選択中のタブはブルー塗り）。その下に「HAND」「FOOT」のカテゴリ（英字・ブルー）ごとに「メニュー名 ……… 価格」の行を並べる。価格は右揃え・改行させない。料金は下表の金額のみ表示（旧料金や値上げ前の金額は載せない）

   | カテゴリ | メニュー | ご新規様 | リピーター様 |
   |---|---|---|---|
   | HAND | ワンカラー | ¥5,000 | ¥5,000 |
   | HAND | グラデーション | ¥5,300 | ¥5,800 |
   | HAND | マグネットワンカラー／ミラーワンカラー／フラッシュワンカラー（同一料金。3行に分けて表示） | ¥5,800 | ¥6,000 |
   | HAND | 定額デザイン | ¥6,300 | ¥6,800 |
   | HAND | クリアネイル | ¥4,800 | ¥4,800 |
   | FOOT | マグネットワンカラー | ¥8,000 | ¥8,000 |
   | FOOT | ワンカラー | ¥7,500 | ¥7,500 |

   この料金データは `site.json` に `menu: [{category, name, priceNew, priceRepeat}]` の形で持たせる
3.5 **スタイリスト**：見出し「STYLIST／スタイリスト」。名前「riho」（Jost 400、28〜34px）と、カテゴリ名「QUALIFICATION」（英字・ブルー）の下に資格を「資格名 ……… 級」の行で表示：JNECネイリスト技能検定 1級／JNAジェルネイル技能検定 上級。写真は載せない。データは `site.json` の `stylists: [{name, qualifications: [{name, level}]}]` に持たせる
4. **はじめての方へ**：予約〜来店〜施術〜お会計の流れを4ステップで横並び（スマホは縦）
5. **よくある質問**：`<details>`で開閉するアコーディオン。5問程度（他店オフ可否／所要時間／持ち込みデザイン／キャンセル規定／駐車場）
6. **ご予約**：ブルー背景の帯（文字・ボタンは生成り）、中央揃え。「ネット予約」（ホットペッパー）と「Instagram」の2ボタン。説明文は「ご予約はホットペッパービューティーから24時間受け付けています。最新のデザインやお知らせはInstagramでご覧いただけます。」
7. **店舗情報・アクセス**：定義リスト（アクセス・営業時間・定休日・お支払い）。住所・地図は載せない
8. **フッター**：ブランド名「sun_r」（Jost 400）・コピーライト・Instagramへのテキストリンク

### 5. UX要件
- **スマホでは画面下部に「予約する」固定バーを表示**（ヒーローを過ぎてから出現、予約セクション表示中とフッター付近では隠す）
- ナビのリンクはスムーススクロール（固定ヘッダー分のオフセットを考慮）
- 予約ボタンは外部サイトに飛ぶので `target="_blank" rel="noopener"`、ボタン横に外部リンクアイコン
- 料金の税込／税抜表記は未確定のため、`site.json` の `taxNote` に入れた文言をメニュー下に小さく表示する（空なら非表示）。定休日・お支払いが未確定の間はアクセス欄に「※定休日・お支払い方法は仮の情報です」を小さく表示（`site.json` の `isSample: true` で切替）
- アニメーション（控えめ・上品に。派手な動きや常時動き続けるものは入れない）
  - 読み込み時：ヒーローのロゴが少し回転しながらふわっと拡大表示（約1秒、わずかに弾む）→ 0.45秒後に「sun_r／PRIVATE NAIL SALON」、0.65秒後にボタンが下から浮き上がる
  - スクロール時：各セクションの中身が、画面に入ったら下から28pxふわっと表示（IntersectionObserver、1回だけ）
  - ホバー：ボタンは2px浮いて薄いブルーの影、ヒーローとヘッダーのロゴは少し傾く
  - 料金タブ切替時：料金の行を0.4秒でフェード
  - ヘッダーは上部に固定（sticky）し、スクロールしたら薄い影を付ける
  - `prefers-reduced-motion: reduce` の環境ではすべてのアニメーションを無効化
- 波の音（BGM）
  - ヘッダーの「SOUND」ボタンを押すと、波の音がループ再生される。初期状態はOFF（ブラウザの自動再生制限のため、必ずユーザーのタップで開始する）
  - 音声ファイルは使わず、Web Audio APIで生成する「穏やかな波打ち際」の音：ブラウンノイズのループを3層重ねる。①寄せる波（ローパス450→1300Hz、音量ピーク0.14〜0.28、3.5〜5.5秒かけて寄せ、5〜8秒かけて引く）②砂を洗う「ザーザー」（バンドパス2200Hz・Q0.35、①が寄せる途中から①の85%程度の音量でしっかり鳴り、引き波とともにゆっくり消える）③遠くのさざめき（ローパス180Hz、常にごく小さく）。波と波の間に0.5〜2秒の間を置き、強さと長さは毎回ランダム。音量変化は setTargetAtTime でなめらかに。全体の音量は0.38程度と控えめにし、開始・停止はゆっくりフェード
  - ON中はボタンの文字をブルーにし、小さな点がゆっくり点滅する。aria-pressed と aria-label（「波の音を再生／停止」）を切り替える
  - タブが非表示になったら一時停止し、戻ったら再開する

### 6. 品質要件
- アクセシビリティ：タップ領域44px以上、フォーカスリング表示、コントラスト比4.5:1以上
- SEO：title・meta description・OGP（og:imageは生成り地にロゴだけのシンプルな画像）・favicon、`LocalBusiness`（NailSalon）の構造化データJSON-LDを `site.json` の内容から出力
- 表示速度：Google Fontsは `display=swap`（画像を使わないので軽量に保つ）
- 文章は全て日本語。架空の口コミや受賞歴などは書かないこと

### 7. 進め方
1. まずファイル構成と `site.json` の雛形を作成
2. PC・スマホ両方のレイアウトを実装
3. 完成後、スマホ幅（375px）とPC幅（1280px）で表示を確認し、崩れがあれば修正
4. 最後に「オーナーが更新するときに触るファイルと項目」を README.md に短くまとめる
